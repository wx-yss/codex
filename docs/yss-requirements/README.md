# YSS 个人需求

这个目录记录 yss 在本 fork 里的个人定制需求。

每个需求使用一个独立 Markdown 文件，描述期望行为、用户侧约束和已知边界。这里的文件只作为需求参考，不要求照搬旧代码；除非某个行为依赖具体实现细节，否则不要在需求里绑定代码方案。

## 文件列表

- `conditional-skill-root-providers.md`：按外部脚本协议动态追加本地 skill roots，用于区分公司和个人环境。
- `double-esc-interrupt.md`：双击 Esc 中断当前 TUI 任务。
- `feature-replication-plan.md`：个人定制功能复刻计划。
- `resume-picker-archive-delete.md`：resume picker 中归档和删除会话。
- `slash-command-recents.md`：斜杠命令最近使用记录。
- `spawn-agent-metadata.md`：TUI 展示 `spawn_agent` 请求元数据。
- `statusline-adjustments.md`：TUI 状态行显示调整。
- `tui-agent-resume-status-markers.md`：TUI agent/resume 状态标记。
- `tui-daily-log-archive.md`：TUI 日志按日归档。
- `tui-mcp-server-management.md`：TUI MCP server 管理弹窗。
- `tui-yss-build-version-display.md`：TUI 展示 YSS 构建版本。
- `user-prompts.md`：用户 prompt 相关定制。
